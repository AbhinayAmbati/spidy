# Spidey v0.1.21

Three fixes.

## The status pill no longer outlives the app

Closing the app from recents used to leave the status pill on screen, over whatever you
opened next. It is a system window, so nothing about the task ending removed it. Closing the
app now hides the pill and stops the task.

## Notifications no longer show "Enable" once they are enabled

The Settings card was reading notification **access** — a separate system switch that lets
Spidey read other apps' notifications — rather than the notification permission itself. Two
different things were being shown as one, so the card reported notifications as off while
they were on. They are now separate cards: **Notifications**, which is the permission and
shows the agent's progress, and **Notification access**, which is optional.

## It stops repeating a search

Once a search had returned results the agent would run it again, rewording the query each
time. A reworded query is a different action, so the existing repeat guard missed it
completely — that guard compares actions to each other, and no two were the same.

There is now a per-task limit on how many times a given tool may run, regardless of its
arguments, and the prompt says plainly not to search again once results are showing, and to
call finish when what the task asked for is already on screen.
