# Spidey v0.1.10

## What changed

**The agent no longer repeats itself.** The most common failure was the same action over and
over — "Opening com.android.chrome" seven times, "Typing Kubernetes" six times. It now
refuses to re-run an action whose arguments are identical to one that already ran and left
the screen unchanged, and tells the model to do something different. If the model keeps
insisting, the task stops with a clear message instead of looping.

**Opening an app you are already in now says so.** `open_app` returns *"Chrome is already the
app on screen, so nothing changed"* instead of reporting a fresh launch — which is what fed
the loop in the first place.

**A stronger system prompt.** It now states plainly that every reply must be a tool call and
never plain text; that an action already performed must not be repeated; that a failed action
must not be retried identically; and how to read the screen listing.

**Searching the web takes one step instead of many.** The prompt now directs the model to
`launch_url` with a search URL such as `https://www.google.com/search?q=…` rather than
driving a browser's interface by hand. "Open Chrome and search for Kubernetes" should no
longer involve tapping a new-tab button at all.

**The model is told when nothing happened.** If an action leaves the screen exactly as it
was, the observation says so — previously it had to infer that.

**New tests** for loop detection (`ActionSignatureTest`).
